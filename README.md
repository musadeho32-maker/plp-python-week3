# Grade Reporter & Bug Hunt

## Files

- `grade_reporter.py`: Uses a for loop and conditions to calculate learner grades, pass and fail counts, and the average score.
- `bug_hunt.py`: Demonstrates debugging by fixing three bugs in a while loop and print statement.

## Bug Hunt Reflection

The hardest bug to find was the incorrect while loop condition because it did not produce an error message. The program ran but stopped before adding 5, giving an incorrect total of 10 instead of 15. I knew something was wrong by comparing the program's output with the expected answer.
